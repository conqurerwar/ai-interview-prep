Project: bePrepared

Built an AI-powered interview preparation platform to generate technical and behavioral questions dynamically.
Integrated Large Language Models (LLMs) to simulate real interview scenarios and provide contextual responses.
Designed a responsive web interface for seamless user interaction and real-time feedback.
Implemented question categorization (DSA, system design, HR) to personalize interview practice sessions.
Developed backend APIs to handle user input, AI processing, and session management.
Enabled performance evaluation by analyzing user responses and suggesting improvements.
Applied prompt engineering techniques to improve accuracy and relevance of AI-generated questions.
Optimized application performance and reduced response latency for better user experience.
Version-controlled the project using Git and followed modular, scalable code practices.
